# 从维滕堡到山上之城

教会史互动课堂，第 6–9 课：

| 课 | 主题 | 年代 |
|---|---|---|
| 6 | 马丁·路德与宗教改革 | 1483–1546 |
| 7 | 慈运理、加尔文与改革宗教会 | 1500–1564 |
| 8 | 英格兰宗教改革 | 1509–1603 |
| 9 | 17 世纪的清教徒 | 1550–1701 |

纯静态网站：没有构建步骤、没有后端、运行时不请求任何 CDN（Google 字体可选，加载失败自动用系统宋体）。

## 打开

- **本机**：直接双击 `index.html`。
- **上线**：仓库 Settings → Pages → 选 `main` 分支根目录，得到 `https://<用户名>.github.io/churchhistory/`。

## 里面有什么

- **首页**：书架（4 课 + 进度）、跨四课的可点击时间轴、欧洲 + 新英格兰地图。
- **每课**：经文 → 要点 → 分章故事（关键词可点开解释）→ 穿插的互动 → 人物卡 → 本课时间轴/地图 → 关键词 → 名言 → 测验 → 小组讨论 → 延伸阅读。
- **互动类型**：分类、排序、对照揭晓、误解翻牌、情境抉择、配对、地图旅程（加尔文）、宗教钟摆（英格兰四朝）、胡珀主教 1551 年考题自测，以及三个特制互动：赎罪券箱、"注入 vs 归算"账本、教堂平面图（祭坛中心 vs 讲台中心）。
- **复习页**：关键词闪卡、随机时间线挑战、"我是谁？"、混合测验。
- **投影模式**：右上角「投影」放大字号，适合上课投屏。

学习进度存在各人浏览器的 localStorage，不上传任何数据。

## 修改内容

每课一个文件 `data/lesson-XX.js`，格式见 [`docs/content-schema.md`](docs/content-schema.md)。改完运行：

```bash
npm test            # 数据格式 + 引擎单元测试（无需安装依赖）
npm run test:e2e    # 浏览器冒烟测试（需要 Playwright）
```

地图数据 `assets/map-data.js` 是生成的；要改地图范围：`npm install && npm run build:map`。

## 请老师核对的史实

正文由讲义改编；第 6、8 课讲义只有提纲，正文按通行教会史补写。以下几处建议上课前核对：

**讲义原文已修正**
- 第 7 课：Bollinger → 布林格（Bullinger）；斯特拉斯堡当时属神圣罗马帝国（非法国）；1538 年法勒尔去的是纳沙泰尔，不是随加尔文去斯特拉斯堡。
- 第 9 课：大驱逐写作"约两千名牧师"（讲义"6000 人中的三分之一"与通行说法不符）；大迁徙写作"约两万人（讲义记为一万）"。

**有争议或来源较晚，文中已标"据传/传统说法"**
- 路德把论纲"钉"在门上、"这是我的立场"是否原话、台彻尔"钱币叮当"口号。
- 慈运理临终语；加尔文"被抬上讲台"讲最后一篇道（有的史料说被抬进教会）。
- 克兰麦"这只手犯了罪"；安妮·博林向亨利推荐丁道尔著作。
- 欧文回答查理二世关于班扬的话。

**年份/数字**
- 胡斯生年：沿用讲义 1369（不少资料作约 1372）。
- 路德赴罗马：写作"1510 年前后"。
- 胡珀 1551 年调查：311 人中 50 人能答、其中 19 人答得差（按讲义）。
- 伊丽莎白对天主教徒的政策：讲义说"先迫害后容忍"，文中写得更细（1570 年后被视为政治威胁）。
- 部分书目中文译名未确定，已在"延伸阅读"备注中说明。
