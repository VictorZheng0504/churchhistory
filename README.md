## 打开

- **本机**：直接双击 `index.html`。
- **上线**：仓库 Settings → Pages → 选 `main` 分支根目录，得到 `https://<用户名>.github.io/churchhistory/`。

## 里面有什么

- **首页**：书架（各课 + 进度）、跨课可点击时间轴（按事件密度伸缩）、地图（自动选能装下所有地点的最小视图：欧洲 + 新英格兰小图、地中海、北美、大西洋两岸、世界）。
- **每课**：经文 → 要点 → 分章故事（关键词可点开解释，章末可能有「批注」）→ 穿插的互动 → 人物卡 → 本课时间轴/地图 → 关键词 → 名言 → 测验 → 小组讨论 → 延伸阅读。
- **互动类型**：分类、排序、对照揭晓、误解翻牌、情境抉择、配对、地图旅程（加尔文）、宗教钟摆（英格兰四朝）、胡珀主教 1551 年考题自测，以及三个特制互动：赎罪券箱、"注入 vs 归算"账本、教堂平面图。
- **复习页**：关键词闪卡、随机时间线挑战、"我是谁？"、混合测验。
- **投影模式**：右上角「投影」放大字号，适合上课投屏。

学习进度存在各人浏览器的 localStorage，不上传任何数据。

## 修改内容

每课一个文件 `data/lesson-XX.js`，格式见 [`docs/content-schema.md`](docs/content-schema.md)。新增一课：写好文件后在 `index.html` 加一行 `<script src="data/lesson-XX.js">`。改完运行：

```bash
npm test            # 数据格式 + 引擎单元测试（无需安装依赖）
npm run test:e2e    # 浏览器冒烟测试（需要 Playwright），自动覆盖 index.html 里的每一课
```

地图数据 `assets/map-data.js` 是生成的；要改地图范围：`npm install && npm run build:map`。

## 内容原则

- **正文以讲义/讲稿为准。** 明显笔误直接改正（如 Iranaeus → Irenaeus、Teztel → Tetzel）。
- **与通行史料不一致处**：正文照讲义写，章末加小字「批注：另有资料作……」。各课批注数：第 1 课 10、第 2 课 11、第 3 课 9、第 4 课 12、第 5 课 16、第 6 课 12、第 7 课 8、第 8 课 6、第 9 课 3、第 10 课 8、第 12 课 14、第 13 课 3。直接在各课 `chapters[].notes` 里搜"另有资料"即可逐条查看。
- 讲稿没有而为衔接补写的内容（生卒年、在位年份、阅读书目、部分经文和信经标准译文）都按通行资料补。

## 请老师核对

**译名**（教会圈译法不一）：德修（Decius）、加勒留（Galerius）、瓦勒良（Valerian）、楚门（Carl Trueman）、欧迪奇（Eutyches）、亚波里拿留（Apollinaris）、反圣灵派（Pneumatomachians）；第 10 课爱德华兹著作书名（《宗教情感》亦作《宗教情操》等）、田能特、昌西、霍利。

**第 10、12、13 课只有大纲**，正文按大纲扩写，衔接细节按通行史料补（例如恩菲尔德讲道、1744 年"不雅书籍事件"、怀特腓讲道次数）。请重点过目。

**第 13 课**讲国会山浸信会（CHBC）的历史，写成"一个地方教会的故事"，并加了一道讨论题请学员回顾自己教会的历史。只出现历史人物和公众牧者的名字。

**讲稿原文、未加批注，建议看是否补一条**
- 第 3 课：讲稿说君士坦丁在尼西亚"同情亚流派"；主流看法是他当时支持"同质"一词。
- 第 4 课：讲稿回顾上一课时说基督"一个位格、一个本质（hypostasis）"，与迦克墩"二性一位格"不符；正文只写"在一个位格里联合"。
- 第 4 课：约翰福音 15:26 讲稿解释为圣灵"从子出来"，与经文不符；正文改写为"主应许差遣圣灵"，并加了批注。
- 第 8 课：查理五世还是其大使勒纳尔、伊丽莎白"由凯瑟琳·帕尔抚养"、处决天主教徒的时间、凯瑟琳的五个孩子——照讲稿写。

**补写的推断，请过目**
- 第 1 课"司提反殉道"年份填 30（约数）；第 2 课小普林尼信写 112、复活节之争写 190。
- 第 4 课讲稿没有结论段，结论章是按三条主线归纳的。
- 第 3 课讲稿里针对美国的提醒，泛化为"不要把任何国家或政府与神立约的子民混为一谈"。
- 第 6 课："皇帝叫停核对书目"写作"据说"；40 天与 21 天期限的出入。

**较早几课已处理的**
- 第 7 课：Bollinger → 布林格；斯特拉斯堡当时属神圣罗马帝国；1538 年法勒尔去的是纳沙泰尔。
- 路德"钉"论纲、"这是我的立场"、台彻尔口号、慈运理临终语、克兰麦"这只手"等，文中标"据传/传统说法"。
